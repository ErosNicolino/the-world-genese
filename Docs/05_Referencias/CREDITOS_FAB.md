# Pacotes da Fab usados no jogo

**Licença:** o usuário conferiu em 11/10/2026 as licenças dos pacotes gratuitos da Fab copiados para o Vortex. A conclusão dele foi que o uso é permitido em jogos pequenos, com vendas abaixo de milhões. Se o jogo passar desse porte, as licenças precisam ser revistas antes.

Pacotes copiados para `Content/` (e por isso empacotados na Alpha):

| Pasta em `Content/` | Pacote | Uso no Vortex |
|---|---|---|
| `ArrowTrail` | Free Arrow Trail | rastro dos projéteis, um por elemento |
| `Basic_VFX` | Basic VFX Pack (Free) | efeitos de golpes e impactos |
| `Free_Spells` | [18] Free Spells Niagara | tornado, parede e magias por elemento |
| `FreeParticle_SoftTofu` | partículas gratuitas (SoftTofu) | efeitos |
| `Vefects` | pacotes de efeitos Vefects (impactos, ondas de choque) | impactos e ondas |
| `FogArea` | Fog Area | névoa do vale |
| `WaterMaterials` | materiais de água | água |
| `FreeModularMagicSFX` | Free Modular Magic SFX | sons de magia das armas |
| `Free_Sounds_Pack` | 50 Free Game Sounds Pack | sons das armas |
| — (exportado para `Data/WeaponSfx/ref`) | Small Sound Kit (Magic) | sons das armas, recortados por `Tools/BuildWeaponSfx.py` |

Os nomes completos de alguns pacotes acima foram deduzidos pela pasta. Confira o nome e o autor de cada um na Biblioteca da Fab e mantenha esta lista atualizada sempre que um pacote novo entrar no jogo. As animações dos pacotes ficam só no projeto `VortexReferencia` (ver `REFERENCIAS_VORTEXREFERENCIA.md`) e não entram no jogo.

O projeto Godot tem regras próprias de som (`AGENTS.md` e `AudioProduction/`); esta lista vale só para o Vortex na Unreal.
